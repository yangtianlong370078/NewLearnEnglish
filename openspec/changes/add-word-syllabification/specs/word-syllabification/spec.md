## 新增需求
### 需求：单词详情音节拆分
系统必须在 `GET /api/Word/lexiconDeatil` 的成功响应中，为非空的 `data` 返回一个名为 `syllables` 的数组字段。该数组必须按原单词顺序包含音节字符串；服务必须优先使用已在应用启动时加载到内存中的 CMU 词典确定拆分，且在 CMU 中没有词条或无法拆分时必须使用内置英文规则拆分作为兜底。Natural.NET 在 NuGet.org 无可用包时不得阻塞该功能。

#### 场景：CMU 词典中存在词条
- **当** 已授权用户请求 CMU 词典包含的单词详情
- **那么** 接口必须在 `data.syllables` 返回该单词按音节顺序拆分的数组
- **并且** 请求处理期间不得重新读取 CMU 词典文件

#### 场景：CMU 词典中不存在词条
- **当** 已授权用户请求 CMU 词典不包含但可由规则拆分的英文单词详情
- **那么** 接口必须在 `data.syllables` 返回内置英文规则拆分的音节数组

#### 场景：没有可返回的词典详情
- **当** 已授权用户请求的单词详情不存在
- **那么** 接口必须维持 `data` 为 `null` 的现有行为
